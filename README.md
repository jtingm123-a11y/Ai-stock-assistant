# A 股研究工作台

一个运行在本地电脑上的 Streamlit A 股股票研究助手，帮助整理行情、技术指标、财务数据和规则化研究结论。

项目不依赖大语言模型，主要面向个人学习、数据整理和投资研究流程管理。所有结果仅供参考，不构成投资建议。

## 主要功能

### 首页

- 输入六位 A 股代码，快速进入个股研究
- 查看股票池数量、最新行情日期和股票池综合涨跌
- 首页不主动加载行情，打开速度更快

### 市场观察

- 查看上证、深证、恒生、标普 500、纳斯达克、日经等主要市场
- 点击刷新后才请求全球行情
- 显示全球行情最近刷新时间
- 部分市场请求失败时单独提示，不影响其他市场显示

### 个股研究

- 获取股票基本信息和日线行情
- 支持 AkShare、腾讯财经、新浪财经行情源
- 自动计算 MA5、MA10、MA20、MA60、MACD、KDJ、RSI
- K 线、成交量和 MACD 共用时间轴，可同步缩放和拖动
- 显示收盘价、涨跌幅、成交量和成交额
- 提供技术面、财务面、趋势强度和风险指标评分
- 提供技术分析师、基本面分析师、风险经理和研究主管视角

### 我的股票池

- 添加、删除和备注自选股
- 查看股票池最新行情
- 支持按添加时间、涨跌幅和代码排序
- 支持批量刷新行情
- 支持从股票池直接进入个股研究
- 股票名称和行情结果使用本地缓存，减少重复请求

### 研究报告

- 生成结构化 Markdown 研究报告
- 报告包含基本信息、关键指标、综合评分、规则化研判和风险提示
- 支持下载报告或保存到 `data/exports`

## 数据可靠性

- 日线行情成功获取后保存到 SQLite 本地数据库
- 新交易日会自动检查行情缓存是否过期
- 行情刷新失败时，已有本地缓存仍可继续使用
- 财务数据默认缓存 24 小时
- 数据页面显示行情来源、数据截止日期和刷新时间
- 数据库启动时自动创建所需数据表

```text

│   ├── analysis/                  # 技术指标、评分和规则分析

```

## 安装和启动

要求：Windows、Python 3.10 或更高版本。

### PowerShell 启动

```powershell
cd "C:\Users\admin\Desktop\AI股票助手"
.\run_app.ps1
```

### 手动启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

在 VS Code 中应启动 Streamlit 应用，不要使用“运行 Python 文件”直接运行页面脚本。

## 使用说明

1. 启动应用并打开“个股研究”。
2. 输入六位股票代码，例如 `600519` 或 `000001`。
3. 点击“开始研究”获取行情和分析结果。
4. 在“我的股票池”中保存需要长期跟踪的股票。
5. 在“研究报告”中生成和导出 Markdown 报告。

首次查询新股票需要联网。数据源可能存在延迟、限流或临时不可用的情况。

## 测试
